# Legacy Backend Compatibility Snapshot

This directory is an archived backend snapshot kept only for historical service and database compatibility research. It is not built, routed, deployed, or presented as the Digital Silk Road application.

The former browser application has been removed. All active product pages, APIs, and reusable image, video, music, digital-human, shot-planning, and timeline capabilities live in the repository root.

Use the root `README.md`, `web/`, `api/`, and `application/` directories for development and deployment.
