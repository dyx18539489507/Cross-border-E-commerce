# 比赛 Demo 演示脚本

## 1. 固定案例

- 商品：智能温显保温杯。
- 类目：家居用品 / Insulated Beverage Containers。
- 目标市场：美国，兼顾英国。
- 目标平台：Amazon、TikTok Shop。
- 用户：22-40 岁通勤人群与礼赠买家。
- 卖点：触碰显示温度、便携防漏、304 不锈钢内胆、通勤与礼赠场景。

这个案例画面容易理解、合规边界清晰，适合展示商品理解、RAG 合规、本地化脚本、数字人和素材工作流。

## 2. 答辩前准备

复制前端演示配置，并在 `web/.env.local` 中启用固定设备：

```bash
cp web/.env.example web/.env.local
```

```env
VITE_DEMO_DEVICE_ID=demo-device-digital-silk-road
```

写入可重复 Demo 数据：

```bash
DEMO_DEVICE_ID=demo-device-digital-silk-road go run ./scripts/seed-demo.go
```

脚本会输出项目 ID、项目路径和 Agent 历史路径。它可以重复执行，不会重复创建同名 Demo 项目；每次执行会刷新 Demo 记录时间。

启动并验收（以下命令分别在三个终端执行）：

```bash
# 终端 1：后端
go run .

# 终端 2：前端
cd web && npm run dev -- --host 127.0.0.1

# 终端 3：验收
API_BASE_URL=http://127.0.0.1:5678 DEVICE_ID=demo-device-digital-silk-road ./scripts/smoke-test.sh
```

## 3. 固定演示路径（建议 6-8 分钟）

1. 首页 `/`，30 秒。
   - 一句话定位：面向跨境中小卖家、外贸工厂和代运营服务商的 AI Agent 智能营销引擎。
   - 强调不是单点文案工具，而是商品、合规、本地化、素材与反馈的任务链。

2. 工作台 `/dashboard` 与项目列表 `/projects`，45 秒。
   - 展示 `[DEMO] 智能温显保温杯出海营销`。
   - 说明项目数、合规完成数、素材数均来自 SQLite，不是前端写死。
   - Demo 图明确标记为本地 seed 素材，不冒充外部 AI 生成结果。

3. Agent 结果 `/agent/result?historyId=<seed 输出的历史 ID>`，90 秒。
   - 展示商品理解、目标市场、合规、本地化、脚本、数字人建议和投放建议。
   - 说明固定历史用于比赛抗网络波动，页面中标记 `demo-seed-no-external-ai`。
   - 有稳定模型 Key 时，再现场运行 `/agent` 的多 Agent workflow，展示 Trace 与 Critic。

4. 项目详情 `/projects/<项目 ID>`，60 秒。
   - 展示商品信息、美国/英国市场、合规等级和项目内容。
   - 进入 `/projects/<项目 ID>/script` 查看营销脚本与镜头规划；内部旧表仅承担兼容存储，不作为页面概念展示。

5. 合规分析 `/compliance`，60 秒。
   - 说明规则库按国家、平台、类目和敏感词检索。
   - 强调输出含风险依据、替代表达和固定法律免责声明。

6. 内容生产 `/media/image`、`/media/video` 与 `/projects/<项目 ID>/editor`，60 秒。
   - 展示图片、视频、音乐、音效、上传和营销时间线 API 已统一收口。
   - 没有供应商 Key 时只展示配置提示或已有素材，不点击后声称生成成功。

7. 数字人 `/digital-human`，45 秒。
   - Demo seed 中的任务明确显示失败原因：未调用第三方供应商。
   - 有火山引擎 Key 时，从项目页创建真实数字人口播并展示历史、状态、结果。

8. 数据分析 `/analytics`，45 秒。
   - 展示平台内项目、素材、成片和分发记录推导的估算指标。
   - 主动说明不是 TikTok Shop、Amazon、Shopee 的真实广告花费、订单或销售额。

## 4. 现场输入模板

```text
商品：智能温显保温杯
描述：304 不锈钢内胆，杯盖触碰显示水温，便携防漏，适合通勤、办公室和礼赠。
目标市场：美国
目标平台：Amazon、TikTok Shop
目标用户：22-40 岁通勤人群与礼赠买家
补充要求：英文口播，30 秒竖屏视频，表达克制，不使用绝对安全承诺。
```

## 5. 网络或 Key 异常时的稳定方案

- Agent 不稳定：打开 seed 生成的历史结果，不声称是本次实时模型输出。
- 图片/视频供应商异常：展示本地 Demo 素材、任务错误状态和统一 API 结构。
- 数字人异常：展示任务历史和明确错误原因，不播放伪造结果。
- 外部音乐不可用：展示本地上传和音效 API，说明公开音乐源受网络与版权策略影响。
- 第三方平台数据不可用：只展示平台内估算分析，不展示虚构销售额或 ROI。
